# Personal-Finance-App
I created a Personal Finance Application to help track monthly spending and keep tabs of annual bills. Helps with tracking savings, spending, etc. Saves locally without using an online DB. Has default values the user can edit in order to track their own finances. 

Just open the html file in a browser to use it locally. The webpage is pretty straight forward to use. Put things in the right categories and you can see values come back to what they are calculated to be.
